## Раздел 1

### Объекты, отношения и интерпретация

В P(atlas) символ atlas — имя объекта, а P — одноместный предикат. Reviewed(anna, atlas) — двухместное отношение с упорядоченными аргументами: Анна проверила Atlas. Перестановка аргументов обычно меняет смысл. Переменная x обозначает произвольный объект из выбранного домена D.

Модель первого порядка задаёт непустой домен, значения имён и отношений. Для D={a,b} можно задать P={a} и Reviewed={(a,b)}. Имена сами по себе не гарантируют, что обозначают разные объекты. Уникальность имён и допущение «в мире только перечисленные объекты» — дополнительные соглашения, не законы стандартной FOL.

## Раздел 2

### Для всех и существует

∀x P(x) означает: каждый объект домена обладает P. ∃x P(x): хотя бы один обладает P. Формула P(x) со свободной x требует значения переменной; предложение ∀x P(x) связывает эту переменную. Следи за областью квантора: ∀x(P(x) → Q(x)) связывает x в обеих частях.

«Все проверенные пакеты подписаны» при домене всех сущностей: ∀x((Package(x) ∧ Checked(x)) → Signed(x)). Если домен заранее состоит только из пакетов, Package можно убрать. Это не косметика: добавленный тип в предпосылке способен разорвать вывод, если принадлежность объекта к типу не установлена.

«Некоторые проверенные пакеты подписаны» переводится ∃x(Package(x) ∧ Checked(x) ∧ Signed(x)). Импликация внутри ∃ дала бы совсем иной смысл: достаточно объекта, который вообще не является проверенным пакетом.

## Раздел 3

### Почему порядок кванторов меняет утверждение

∀x∃y Reviewed(y,x): у каждого объекта есть какой-то проверяющий; выбор y может зависеть от x. ∃y∀x Reviewed(y,x): есть один проверяющий всех объектов. Во второй формуле свидетель y выбирается сразу для всех x.

Контрмодель обратного перехода: D={a,b}, Reviewed={(a,a),(b,b)}. Каждый объект проверяет сам себя. Первая формула истинна, второй нет: ни a, ни b не проверяют обоих. Это конечная модель, которую можно полностью перечислить.

| Формула | Выбор свидетеля |
| --- | --- |
| ∀x∃y R(x,y) | Для каждого x свой подходящий y |
| ∃y∀x R(x,y) | Один y подходит всем x |

## Раздел 4

### Отрицание кванторов и пустые классы

¬∀x P(x) эквивалентно ∃x ¬P(x): чтобы опровергнуть универсальное утверждение, достаточно одного исключения. ¬∃x P(x) эквивалентно ∀x ¬P(x): отсутствие любого свидетеля означает отрицание для всех объектов.

∀x(P(x) → Q(x)) не гарантирует существования P. Если P пуст, условие истинно для каждого объекта, потому что его предпосылка ложна. Непустой домен не означает непустоту каждого класса. Чтобы гарантировать хотя бы один P, нужна отдельная посылка ∃x P(x).

## Раздел 5

### Правила работы со свидетелями

Из ∀x P(x) можно получить P(a). Из P(a) можно получить ∃x P(x). Но из ∃x P(x) нельзя просто получить P(atlas): существующий объект может быть другим. В доказательстве допустим временный свежий свидетель с ограничениями, которые не позволяют приписать ему заранее известную личность.

Для ∀-введения объект должен быть произвольным: доказательство P(a) не должно зависеть от особых предположений об a. Наблюдение одного подписанного пакета не доказывает, что подписаны все. Перед формализацией выпиши домен, значения имён, арность отношений и область каждого квантора.

## Задачи и самопроверка

Сначала запиши свой ответ. Затем раскрой разбор и сравни именно ход решения.

### Задача 1

«Каждый автор подписал хотя бы одну запись». Напиши формулу для домена всех сущностей с Author, Record и Signs.

> [!answer]- Разбор
> ∀x(Author(x) → ∃y(Record(y) ∧ Signs(x,y))). Условие Author ограничивает x, а Record входит в конъюнкцию под ∃. Эта формула не утверждает существования авторов.

### Задача 2

Из ∀x(P(x) → Q(x)) следует ли ∃x Q(x)? Дай контрмодель.

> [!answer]- Разбор
> Нет. Возьми D={a}, P=∅, Q=∅. Универсальное условие истинно, существование Q ложно. Нужна дополнительная посылка о существовании P или Q.

Дополнительная практика: [задание 5](13-practice.md#задание-5).
